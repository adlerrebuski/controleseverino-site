# Páginas públicas do Severino

Site estático preparado para `controleseverino.online`. Os arquivos podem ser publicados pelo GitHub Pages a partir da raiz da branch `main`, sem contratar hospedagem web adicional na Hostinger.

Após publicar o site:

1. Configurar o domínio personalizado `controleseverino.online` no GitHub Pages.
2. Substituir o registro A padrão da Hostinger pelos quatro endereços oficiais do GitHub Pages. O CNAME `www` pode apontar para `adlerrebuski.github.io`.
3. Confirmar que `https://controleseverino.online/` e `https://controleseverino.online/privacy.html` abrem publicamente.
4. Verificar a propriedade do domínio no Google Search Console com a conta `adlerrebuski@gmail.com`.
5. Configurar as URLs na marca do projeto OAuth `severino-agenda-e-gmail` e solicitar publicação/verificação conforme o Google exigir.

Até a publicação do OAuth, o aplicativo permanece em modo de teste e a autorização pode expirar.
